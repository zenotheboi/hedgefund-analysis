# Hedge Fund Analysis: Clinical Trial Outcome Prediction

## Purpose

The primary objective of this repository is to investigate the feasibility of building a successful hedge fund centered around a predictive model for clinical trial outcomes. 

**Important Scope Note:** This analysis strictly focuses on therapeutics clinical trials for **small molecules and/or small peptides**. No other modalities or trial types are considered in this investigation.

## Methodology & Project Phases

This investigation is structured into the following sequential steps:

### Step 1: Price Movement Archetype Analysis
Analyze historical price movement archetypes of biopharmaceutical stocks resulting from the announcement of clinical trial outcomes. This includes analyzing the impact of both positive and negative results across Phase 1, Phase 2, and Phase 3 trials. 

### Step 2: Perfect Information Backtesting (100% Accuracy)
Backtest various trading strategies assuming our predictive model is 100% accurate. Given the historical ~90% failure rate in clinical trials and the corresponding market anticipation of failure, we will evaluate strategies such as:
*   Long positions
*   Short selling
*   Long positions + renting out shares to short sellers

### Step 3: Realistic Accuracy Backtesting (90% Accuracy)
Identify the optimal strategy derived from Step 2 and backtest it assuming a high, yet imperfect, model accuracy of 90%.

### Step 4: True Model Predictions Backtesting
Perform a final backtest of the optimal strategy using the actual, empirical predictions generated by our true predictive model.

## Using this repo

### 1. Get the code
```bash
git clone https://github.com/zenotheboi/hedgefund-analysis.git
cd hedgefund-analysis
```

### 2. View the analysis report (easiest — no setup)
The full write-up (CAR/CAAR pricing analysis + the $10M backtest, sensitivity,
and scenarios) lives in a single self-contained HTML file:

```
reports/biopharm_car_analysis.html
```

Open it directly in any browser — no server needed:
```bash
open reports/biopharm_car_analysis.html          # macOS
# or: xdg-open reports/biopharm_car_analysis.html  # Linux
```
All charts are embedded, so the file works offline. (A live shared copy may
also be published as a link — ask the maintainer.)

### 3. Run the notebook (interactive)
The CTOD/EDGAR-track methodology notebook is `notebooks/methodology_and_analysis.ipynb`.

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
jupyter lab                      # then open notebooks/methodology_and_analysis.ipynb
```
There is also a `.claude/launch.json` with a `jupyter-lab` and a `report-preview`
(static server for `reports/`) config for editor-integrated preview.

### 4. Reproduce the backtest from scratch
Scripts are numbered in run order under `scripts/`. The backtest pipeline:
```bash
source venv/bin/activate
python scripts/40_extract_phase_outcomes.py      # parse trial outcomes from text
python scripts/41_price_expanded_universe.py     # pull prices + CAR (hits yfinance)
python scripts/42_run_backtest.py                # $10M sim -> reports/backtest_*.png
python scripts/43_sensitivity.py                 # tornado + bear/base/bull scenarios
```
`scripts/quick_stats.py` is a standalone, no-download calculator for ad-hoc CAR
cuts (edit the parameters at the top, then run).
